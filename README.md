## Contents

## Getting Started

### View the presentation

1. Clone this repository:

   ```bash
   git clone https://github.com/aviyahb/JAVA-PROJECT.git
   cd JAVA-PROJECT
   ```

2. Open `JAVA PROJECT.pptx` with Microsoft PowerPoint, LibreOffice Impress, or another compatible presentation viewer.

## Requirements

- A presentation viewer compatible with `.pptx` files
- Java Development Kit (JDK), if Java source code is added to the project later
